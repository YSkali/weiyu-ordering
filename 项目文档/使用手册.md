## 1. 日常启动流程

每次开机后，按以下顺序操作：

### 第1步：确认 MySQL 运行

确保 MySQL 服务已运行（一般开机自启）。可在任务管理器 → 服务中确认。

### 第2步：启动后端

```bash
cd y:\一二布布点菜项目开发\server
npm run start:dev
```

看到 `味遇点餐系统后端服务已启动: http://localhost:3000` 表示成功。保持终端窗口不要关闭。

### 第3步：启动 cpolar

```bash
Y:\cpolar_home\cpolar.exe tcp 3000
```

关键输出确认：
```
Forwarding tcp://xx.tcp.cpolar.top:xxxx -> tcp://127.0.0.1:3000   # 看到 3000 就对了
```

> **注意**：免费版 cpolar 每次重启会分配随机域名和端口，必须用命令行指定端口。

### 第4步：更新前端配置

拿到 cpolar 给的公网地址后，编辑 `12/utils/config.js`：

```javascript
export const BASE_URL = 'http://xx.tcp.cpolar.top:xxxx/v1'
```

### 第5步：HBuilderX 运行

HBuilderX → 运行 → 运行到浏览器。测试登录是否正常。

### 启动流程速查

```
┌─────────────────────────────────────────────┐
│  1. 确认 MySQL 服务正在运行                    │
│  2. 启动后端：                                │
│     cd server && npm run start:dev           │
│  3. 启动 cpolar（命令行方式）：                │
│     Y:\cpolar_home\cpolar.exe tcp 3000       │
│  4. 记下公网地址，更新前端 config：             │
│     编辑 12/utils/config.js                   │
│  5. HBuilderX 运行到浏览器，测试登录            │
└─────────────────────────────────────────────┘
```

## 2. 获取分享链接

### 获取方式

cpolar 启动后，终端会显示公网地址：
```
Forwarding tcp://xx.tcp.cpolar.top:xxxx -> tcp://127.0.0.1:3000
```

这个 `tcp://xx.tcp.cpolar.top:xxxx` 就是分享链接的基础。

### 验证链接可用

1. 浏览器打开 `http://xx.tcp.cpolar.top:xxxx`，能看到登录页面 → 前端正常
2. 管理员登录（admin1 / 123456）→ 后端和数据库正常
3. 顾客登录（新账号 + 口令）→ 整个流程通了

### 分享给朋友

```
链接：http://xx.tcp.cpolar.top:xxxx    ← cpolar 给你的地址
登录方式：顾客登录
账号：随便起一个（首次会自动注册）
密码：自己设一个（牢记）
口令：xxxxx                            ← 管理员设置的口令
```

### 分享后的注意事项

- **电脑不能关机**（后端和 cpolar 必须一直运行）
- **终端窗口不能关**
- 如果重启了，按"日常启动流程"重新操作，cpolar 域名会变

## 3. cpolar 故障排查

### 3.1 转发到错误端口（80 而非 3000）

**现象**：cpolar 显示 online，但转发目标是 `localhost:80` 而非 `localhost:3000`。

**原因**：cpolar 存在两层配置，云端配置优先级高于本地：

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 高 | cpolar 服务器端（云端） | 通过网页后台 dashboard.cpolar.com 或客户端 UI 创建的隧道 |
| 低 | 本地配置文件 | `C:\Users\<用户名>\.cpolar\cpolar.yml` |

之前通过桌面客户端或网页后台创建的旧隧道（端口 80、3389 等）保存在云端，会覆盖本地配置。

**解决步骤**：

1. 浏览器打开 https://dashboard.cpolar.com → 登录 → 「隧道管理」→ **删除所有旧隧道**
2. 用命令行强制指定端口：`Y:\cpolar_home\cpolar.exe tcp 3000`

### 3.2 "Tunnel 数超过限制"

**原因**：免费版有隧道数量上限，云端有旧隧道未删除。

**解决**：去 https://dashboard.cpolar.com 删除旧隧道。

### 3.3 cpolar service stop 报 Access is denied

**解决**：
- 管理员 PowerShell 执行 `sc.exe stop CpolarService`
- 或直接在任务管理器中结束 `cpolar.exe` 进程

### 3.4 TCP 隧道 vs HTTP 隧道

| 类型 | 命令 | 前端访问方式 |
|------|------|-------------|
| TCP | `cpolar tcp 3000` | `http://域名:端口/v1` |
| HTTP | `cpolar http 3000` | `https://域名/v1`（自带 HTTPS） |

本项目使用 TCP 隧道即可。

### 3.5 免费版域名每次重启会变

是的。每次重启 cpolar 都需要更新 `12/utils/config.js` 中的地址。

## 4. cpolar 地址变动处理

免费版 cpolar 每次重启域名会变，需要改两个地方：

### 4.1 修改前端配置

**文件**：`12/utils/config.js`

```javascript
export const BASE_URL = 'http://新地址.cpolar.top:xxxx/v1'
```

### 4.2 重新编译前端

HBuilderX → 菜单栏「发行」→ 「网站-PC Web」

### 4.3 部署到后端

编译完成后，PowerShell 执行：

```powershell
Remove-Item y:\一二布布点菜项目开发\server\public\* -Recurse -Force; Copy-Item y:\一二布布点菜项目开发\12\unpackage\dist\build\web\* y:\一二布布点菜项目开发\server\public\ -Recurse
```

这条命令是固定的，每次编译完直接执行就行。

### 4.4 完成

刷新浏览器，用新地址访问即可。

## 5. 数据库管理

### 连接信息

| 项目 | 值 |
|------|-----|
| 工具 | Navicat |
| 主机 | localhost |
| 端口 | 3306 |
| 数据库 | weiyu |
| 用户名/密码 | 你安装 MySQL 时设置的 |

### 常用 SQL

**查看所有用户**
```sql
SELECT uid, account, nickname, role, points, admin_uid FROM user;
```

**查看所有订单**
```sql
SELECT order_id, uid, status, total_points, created_at FROM `order` ORDER BY created_at DESC;
```

**查看积分流水**
```sql
SELECT * FROM points_flow ORDER BY created_at DESC LIMIT 50;
```

**手动给用户充值积分**
```sql
-- 先查用户 uid
SELECT uid, nickname, points FROM user WHERE nickname = '小明';
-- 加 500 积分
UPDATE user SET points = points + 500 WHERE uid = 2;
-- 记录流水
INSERT INTO points_flow (uid, change, type, remark) VALUES (2, 500, 'admin_add', '管理员手动充值');
```

**重置管理员密码**（密码重置为 123456）
```sql
UPDATE user SET password = '$2b$10$VBo.UDaCq2Bpzs8aXHWK9O2yaeCkER8Bxx8cFS8uC6DhxJt19MBs6' WHERE account = 'admin1';
```

**查看管理员列表**
```sql
SELECT uid, account, nickname, group_code FROM user WHERE role = 'admin';
```

**清空测试数据重新开始**
```sql
SET FOREIGN_KEY_CHECKS = 0;
TRUNCATE TABLE order_item;
TRUNCATE TABLE `order`;
TRUNCATE TABLE points_flow;
TRUNCATE TABLE comment;
TRUNCATE TABLE exchange_request;
DELETE FROM user WHERE role = 'customer';
SET FOREIGN_KEY_CHECKS = 1;
```

## 6. 前端修改与重新编译

### 项目结构

```
12/
├── pages/                   ← 所有页面
├── components/              ← 公共组件
├── utils/
│   ├── config.js            ← cpolar 地址在这里改
│   ├── request.js           ← 网络请求封装
│   └── auth.js              ← 登录相关函数
├── api/                     ← API 接口函数
├── store/                   ← 状态管理
├── App.vue                  ← 全局样式
├── pages.json               ← 路由配置
└── manifest.json            ← 项目配置
```

### 修改后重新编译

1. HBuilderX 中修改代码 → 保存（Ctrl+S）
2. 「发行」→「网站-PC Web」
3. PowerShell 执行部署命令（见 4.3 节）
4. 刷新浏览器

### 添加新页面

1. `12/pages/` 下新建 `.vue` 文件
2. `12/pages.json` 中注册页面路径
3. 重新编译部署

### 修改颜色主题

全局颜色定义在 `12/App.vue` 的 CSS 变量中，修改变量即可全局生效。

## 7. 后端修改与重启

### 项目结构

```
server/
├── src/
│   ├── main.ts              ← 入口
│   ├── app.module.ts        ← 根模块
│   ├── entities/            ← 数据库实体
│   ├── modules/             ← 业务模块（auth/dish/order/user/comment/exchange）
│   └── common/              ← 公共工具
├── public/                  ← H5 前端文件（编译后放这里）
├── uploads/                 ← 上传的图片
├── database.sql             ← 数据库初始化脚本
├── package.json             ← 依赖配置
└── .env                     ← 环境变量
```

### 修改后端后重启

`npm run start:dev` 是开发模式，修改代码后自动重启，不需要手动操作。

### 添加新的 API 接口

1. 对应模块下添加 controller 方法
2. 重启后端（自动）
3. 前端调用新接口

### 修改数据库表结构

- **方式一**（推荐）：直接在 Navicat 里用 SQL 语句修改
- **方式二**：修改 `src/entities/*.entity.ts` 字段定义（需 `synchronize: true`，生产环境不推荐）

## 8. 内置管理员账户

| 账号 | 密码 | 说明 |
|------|------|------|
| admin1 | 123456 | 管理员1（主账户） |
| admin2 | 123456 | 管理员2 |
| admin3 | 123456 | 管理员3 |
| admin4 | 123456 | 管理员4 |
| admin5 | 123456 | 管理员5 |

- 内置管理员不支持注册，只能用这 5 个
- 可以在「我的」页面修改密码和口令
- 每个管理员有独立的口令，管理自己的顾客组

### 顾客登录流程

```
输入：账号 + 密码 + 口令
→ 首次登录：自动注册，密码即为以后的登录密码
→ 再次登录：直接进入
```

### 口令机制

- 管理员在「我的」→「管理口令」设置口令
- 告诉朋友口令，朋友用口令登录
- 修改口令后，正在使用中的顾客需要用新口令重新登录

## 9. 常见问题排查

### 页面打不开 / 白屏

- 检查后端是否在运行（终端窗口）
- 检查 cpolar 是否在运行
- 检查 config.js 的地址是否和 cpolar 一致

### 登录提示"密码错误"

- 管理员密码可在 Navicat 中重置（见第 5 节）

### 管理员登录不了

```sql
-- 确认 account 字段有值
SELECT uid, account FROM user WHERE role = 'admin';
-- 如果 account 为空
UPDATE user SET account = 'admin1', password = '$2b$10$VBo.UDaCq2Bpzs8aXHWK9O2yaeCkER8Bxx8cFS8uC6DhxJt19MBs6' WHERE uid = 1;
```

### cpolar 域名变了

参考第 4 节修改 config.js → 重新编译 → 部署。

### 后端启动报错

- 检查 MySQL 是否运行
- 检查 `.env` 文件中的数据库密码是否正确
- 检查端口 3000 是否被占用

### 图片上传不生效

- 图片保存在 `server/uploads/` 目录
- 访问地址：`http://localhost:3000/uploads/文件名.jpg`

### 小程序端使用

- 小程序的 BASE_URL 在同一个 config.js
- 需要在开发者工具中勾选「不校验合法域名」或在微信公众平台配置合法域名
