# 味遇点餐 — 顾客使用指南

> 本文档面向使用味遇点餐系统的顾客，介绍各功能的操作方法。

---

## 一、首次登录

1. 打开应用，进入登录页面
2. 输入**账号**和**密码**（由管理员提供或自行设置）
3. 输入**分组口令**（管理员提供的口令码）
4. 点击「登录」即可进入首页

> 首次输入口令会自动注册，之后登录不需要再输入口令。账号和密码即为你的登录凭据，请牢记。

---

## 二、浏览菜品

1. 首页顶部有**分类栏**，左右滑动可切换分类
2. 点击分类名称，下方菜品列表会自动筛选
3. 顶部**搜索框**可输入关键词搜索菜品
4. 菜品卡片显示：图片、名称、积分价格
5. 有**活动价**的菜品会显示特价（原价划线）

---

## 三、点餐下单

1. 点击菜品卡片进入**详情页**，查看大图和描述
2. 点击「加入购物车」按钮
3. 切换到**购物车**页面（底部导航第2个）
4. 调整菜品数量（+/- 按钮）
5. 点击「去结算」提交订单

> 提交订单时不会扣积分，等管理员接单后才扣。

---

## 四、查看订单

1. 点击「去结算」后自动跳转到**订单列表**
2. 顶部可按状态筛选：待接单 / 制作中 / 已完成
3. 点击订单卡片查看详情
4. 管理员完成制作后，点击「确认收货」完成订单

### 订单状态说明

| 状态 | 含义 |
|------|------|
| 待接单 | 已提交，等待管理员确认 |
| 制作中 | 管理员已接单，积分已扣 |
| 已完成 | 管理员已完成制作 |
| 已确认 | 你已确认收货，订单结束 |

---

## 五、每日签到

1. 进入**积分中心**（底部导航第3个）
2. 点击「签到」按钮
3. 每日签到可获得 **10 积分**
4. 签到后按钮变为「已签到」

---

## 六、积分兑换

1. 在**积分中心**页面，点击「去兑换」
2. 浏览可用的奖励列表
3. 点击奖励可查看详情和所需积分
4. 积分足够时点击「兑换」
5. 等待管理员审核通过

---

## 七、发表评论

1. 进入**菜品详情页**
2. 如果该菜品开启了评论功能，页面下方有评论区
3. 选择评分（1-5星）
4. 输入评论内容，点击「发表评论」

---

## 八、个人中心

进入**我的**页面（底部导航第4个），可以：

| 功能 | 说明 |
|------|------|
| 修改昵称 | 30天内只能修改一次 |
| 修改密码 | 需要输入旧密码 |
| 修改账号 | 需要输入密码确认 |
| 查看积分 | 显示当前积分余额 |
| 查看订单 | 跳转到订单列表 |

---

## 九、常见问题

**Q: 登录提示「积分不足」怎么办？**
A: 联系管理员为你的账户充值积分。

**Q: 下单后想取消怎么办？**
A: 在管理员接单之前，订单状态为「待接单」，此时不会扣积分。联系管理员取消即可。

**Q: 为什么有些菜品看不到？**
A: 已下架的菜品不会显示。只有管理员上架的菜品才能浏览和下单。

**Q: 积分怎么获得？**
A: 每日签到（10积分）、管理员手动充值、订单完成奖励。

**Q: 口令是什么？**
A: 口令由管理员提供，用于加入对应的管理组。每个管理员有独立的口令。

**Q: 修改昵称后登录不了了？**
A: 修改昵称会同步更新登录账号。用新昵称作为账号登录即可。
